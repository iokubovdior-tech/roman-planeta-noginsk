# Роман · Планета · Ногинск

Личный сайт агента недвижимости на Next.js: портфолио закрытых сделок и призыв для продавцов.

## Запуск

```powershell
cd C:\Users\Roman\roman-planeta-noginsk
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

Проверка сборки:

```powershell
npm run build
npm start
```
